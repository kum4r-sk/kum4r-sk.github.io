# Portfolio site

Static site: `index.html`, `styles.css`, `script.js`, `assets/`. No build step.

## Before publishing
1. Replace `YOURNAME` in `index.html` (2 places) with your GitHub username.
2. Add your CV as `cv.pdf` in this folder.
3. Replace `assets/fig1_network.png` and `assets/fig3_inertia.png` with the hourly
   versions from `isolated-grid-services/figures/`.

## Publish on GitHub Pages
1. Create a public repository named exactly `YOURNAME.github.io`.
2. Upload these files to the repository root (index.html must be at the top level).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at https://YOURNAME.github.io
